# Contributing to Overflow Browser

Thank you for contributing to Overflow Browser!

## Core Principles
- 100% Kotlin with Jetpack Compose & Material Design 3.
- Privacy-first: local-only data, zero telemetry, no tracking SDKs.
- Clean separation of concerns between BrowserViewModel, WebView clients, and storage repositories.

## Workflow
- Fork the repository and create focused, independent feature branches.
- Follow Conventional Commits for commit messages.
- Co-authorship is encouraged via standard `Co-authored-by:` trailers.
