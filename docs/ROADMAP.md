# Overflow Browser — Product & Engineering Roadmap

This roadmap outlines targeted features and architectural enhancements planned for subsequent releases of Overflow Browser.

## Phase 1: Core Experience (v1.0.x - Current)
- [x] Lightweight Compose UI with Material Design 3.
- [x] Built-in host ad & tracker blocker.
- [x] Multi-tab manager with Incognito separation.
- [x] Reader mode distraction-free view.
- [x] Manual GitHub Actions workflow (`workflow_dispatch`) for artifact builds.

## Phase 2: Power-User & Privacy Upgrades (v1.1.x)
- [ ] **Custom Adblock Subscriptions**: Allow users to import custom EasyList / AdGuard filter rules.
- [ ] **Site-Specific Permissions**: Granular toggles for JavaScript, cookies, and location on a per-domain basis.
- [ ] **Custom Search Engines**: Support adding arbitrary OpenSearch-compatible search engines with custom URL templates.
- [ ] **Export / Import**: Encrypted local backup and restore for bookmarks and settings.

## Phase 3: Advanced Media & Platform Features (v1.2.x)
- [ ] **In-App PDF Viewer**: Render downloaded and embedded PDF documents directly within the browser without external viewer dependencies.
- [ ] **Desktop Mode Custom User-Agents**: Per-site desktop site overrides with configurable User-Agent strings.
- [ ] **Download Acceleration**: Multi-threaded chunked downloads for large files.
- [ ] **Biometric Tab Locking**: Optional fingerprint or device PIN unlock before accessing private tabs.
